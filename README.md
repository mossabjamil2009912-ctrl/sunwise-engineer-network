# Sunwise Engineer Network

أنشئ تطبيق ويب وتطبيق هاتف (PWA) مستقل واحترافي باللغة العربية باسم:

"ACTS – منصة أكتس لأنظمة الطاقة وحلولها (Energy Systems & Solutions)"



التطبيق مخصص للعملاء والمهندسين، بواجهة داكنة راقية وفخمة (Dark Theme)، سريعة ومتجاوبة مع الجوال بالكامل، ويتكون من 3 مسارات رئيسية وشاشة تقييم مستقلة:



1. شريط التنقل السفلي (Bottom Navigation) يضم:

   - عرض سعر (حساب منظومة وطلب عرض سعر)

   - دليل المهندسين (استعراض الكفاءات وطلب خدمة هندسية)

   - انضم إلينا (تسجيل المهندسين والطلاب)



2. مسار عرض السعر (Customer Quote Flow):

   - واجهة خطوات تفاعلية ومطابقة لمنطق حسابات الطاقة:

     1) نوع المنظومة: سكني (Residential) أو تجاري (Commercial).

     2) طريقة التقدير: مبلغ الفاتورة الشهرية أو الاستهلاك بالكيلوواط.

     3) نسبة التشغيل (ليل / نهار): خيارات (50% ليل / 50% نهار، 30% ليل / 70% نهار، 70% ليل / 30% نهار).

     4) اقتراح 3 فئات من المنظومات:

        - الخيار المتوازن (الموصى به)

        - خيار السعر الاقتصادي

        - خيار أداء أعلى وسعة بطاريات أكبر

     5) خيار إضافي لطلب تقرير هندسي (PVsyst) أو مخطط أحادي (SLD).

     6) إدخال بيانات التواصل (الاسم، الهاتف، المحافظة/المدينة) وإرسال الطلب.



3. بوابة دليل المهندسين (Engineers Directory):

   - شريط بحث وفلاتر بحسب (التخصص الهندسي، المحافظة، نوع الخدمة المقدمة).

   - بطاقات أنيقة للمهندسين تظهر: الصورة، الاسم، التخصص، المحافظة، سنوات الخبرة، التقييم بالنجوم، وشارة التخصص.

   - صفحة الملف الكامل للمهندس:

     * المؤهلات الأكاديمية والجامعة وسنة التخرج.

     * المهارات والقدرات والبرامج التي يجيدها (AutoCAD, PVsyst, MATLAB...).

     * الخدمات التي يقدمها (تركيب، صيانة، تصميم، إشراف...).

     * معرض المشاريع السابقة مع الصور ونبذة عن كل مشروع.

     * التقييمات السابقة مع متوسط التقييم ومراجعات العملاء وزر إبلاغ عن تقييم.

     * زر بارز: "طلب خدمة هندسية" يفتح نموذجاً لتحديد نوع الخدمة، موقع المشروع، وصف العمل، وإرفاق ملفات/صور.



4. مسار استقطاب الكفاءات الهندسية (Join ACTS - 8 Steps Wizard):

   - نموذج تفاعلي مخصص للطلاب والخريجين والمهندسين ذوي الخبرة:

     1) الحساب: الاسم الكامل، رقم الهاتف، البريد الإلكتروني، والتصنيف (طالب / خريج / مهندس ممارس).

     2) التخصص الهندسي: (كهربائية، ميكانيكية، طاقة متجددة، تحكم وأتمتة، اتصالات، ميكاترونكس، إلكترونيات، تقنية معلومات).

     3) الدراسة والمؤهلات: الجامعة، سنة التخرج، المؤهل العلمي.

     4) المهارات والبرامج: اختيار المهارات الهندسية والبرامج التخصصية.

     5) الخدمات: تحديد الخدمات التي يمكنه تقديمها.

     6) الخبرات والمشاريع: سنوات الخبرة، المشاريع السابقة وصور الأعمال.

     7) الموقع: المحافظة والمدينة.

     8) مراجعة شاملة للبيانات وزر إرسال بانتظار اعتماد الإدارة.



5. شاشة تقييم الخدمة المستقلة (/rate/:token):

   - صفحة خاصة بـ Token مشفر تفتح لتقييم مهندس بعد اكتمال الخدمة.

   - تقييم 5 نجوم مع تفصيل: جودة العمل، الالتزام بالمواعيد، الاحترافية، وسرعة الاستجابة، مع كتابة تعليق.



6. الهوية والتصميم والتكامل:

   - هوية ACTES الرسمية (ألوان داكنة راقية، لمسات أحمر ACTES وأبيض).

   - دعم التثبيت كتطبيق هاتف PWA مع أيقونة واضحة وشاشة بداية أنيقة.

   - التطبيق يتكامل مع خادم CRM الخارجي (https://actes-crm.lovable.app) لإرسال طلبات عروض الأسعار، طلبات الخدمات، بيانات المهندسين، والتقييمات.
